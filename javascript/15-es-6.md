# 1. Destructuring

## What is it?

Extract values from arrays or properties from objects.

### Array Destructuring

```javascript
const arr = [10, 20, 30];

const [a, b, c] = arr;
```

### Object Destructuring

```javascript
const user = {
    name: "Anil",
    age: 27
};

const { name, age } = user;
```

### Rename Variables

```javascript
const { name: userName } = user;
```

### Default Values

```javascript
const { city = "Mumbai" } = user;
```

---

# 2. Spread Operator (...)

## Purpose

Expands an iterable or object.

### Array Copy

```javascript
const copy = [...arr];
```

### Object Copy

```javascript
const copy = { ...user };
```

### Merge Arrays

```javascript
const arr3 = [...arr1, ...arr2];
```

### Merge Objects

```javascript
const obj = {
    ...user,
    age: 28
};
```

### Important

Spread performs a **shallow copy**, not a deep copy.

---

# 3. Rest Operator (...)

## Purpose

Collect multiple values into one variable.

### Function Parameters

```javascript
function sum(...nums) {
    return nums.reduce((a, b) => a + b);
}
```

### Object Rest

```javascript
const { name, ...rest } = user;
```

---

# Spread vs Rest

| Spread | Rest |
|---------|------|
| Expands values | Collects values |
| Usually RHS | Usually LHS |

# 8. Symbol

## What is Symbol?

A unique primitive value.

```javascript
const id = Symbol();
```

```javascript
Symbol() === Symbol();
```

Output

```text
false
```

### Use Case

Avoid object property collisions.

```javascript
const id = Symbol();

const user = {
    [id]: 101
};
```

# 9. BigInt

Used for integers larger than `Number.MAX_SAFE_INTEGER`.

```javascript
const num = 12345678901234567890n;
```

or

```javascript
const num = BigInt(123);
```

Cannot mix Number and BigInt.

```javascript
1n + BigInt(1);
```

# 10. Iterators ⭐⭐⭐⭐⭐

## What is an Iterator?

An object with a `next()` method that returns:

```javascript
{
    value,
    done
}
```

Example

```javascript
const arr = [10,20,30];

const iterator = arr[Symbol.iterator]();

console.log(iterator.next());
```

Output

```javascript
{
    value:10,
    done:false
}
```

---

## Why do Iterators Exist?

To provide a **common iteration protocol** for different data structures.

Instead of knowing how Arrays, Strings, Maps, and Sets store data internally, JavaScript only calls:

```javascript
iterator.next();
```

This enables features like:

- for...of
- Spread (...)
- Destructuring
- Array.from()

---

## Iterable vs Iterator

### Iterable

Has

```javascript
Symbol.iterator()
```

Examples

- Array
- String
- Map
- Set
- Generator Object

---

### Iterator

Returned by

```javascript
obj[Symbol.iterator]()
```

Has

```javascript
next()
```

---

## How for...of Works Internally

Conceptually:

```javascript
const iterator = arr[Symbol.iterator]();

while (true) {

    const result = iterator.next();

    if (result.done) break;

    console.log(result.value);

}
```

---

## Which Types are Iterable?

| Type | Iterable |
|------|----------|
| Array | ✅ |
| String | ✅ |
| Map | ✅ |
| Set | ✅ |
| Generator Object | ✅ |
| TypedArray | ✅ |
| Plain Object | ❌ |

# 11. Generators ⭐⭐⭐⭐⭐

## What is a Generator?

A special function that automatically creates an iterator.

```javascript
function* numbers() {

    yield 10;

    yield 20;

    yield 30;

}
```

Calling it:

```javascript
const gen = numbers();
```

returns a **Generator Object**, not the values.

---

## yield

`yield` means:

- Return a value
- Pause execution
- Resume on the next `next()` call

Example

```javascript
function* demo() {

    console.log("A");

    yield 1;

    console.log("B");

    yield 2;

}
```

Execution

```javascript
const gen = demo();

gen.next();

gen.next();
```

Output

```text
A
B
```

---

## Generator vs Normal Function

| Normal Function | Generator |
|----------------|-----------|
| Runs completely | Can pause |
| One return | Multiple yields |
| Cannot resume | Can resume |
| Returns one value | Returns an iterator |

---

## Why Generators Exist?

Without generators, we manually write:

- next()
- index
- done
- state management

Generators automatically handle all of this.

---

## Real Use Cases

### Lazy Evaluation

Generate values only when needed.

### Infinite Sequences

```javascript
function* ids() {

    let id = 1;

    while(true){
        yield id++;
    }

}
```

### Large Data Processing

Process one record at a time instead of loading everything into memory.

### Custom Iterables

```javascript
class Range {

    constructor(start,end){
        this.start = start;
        this.end = end;
    }

    *[Symbol.iterator](){

        for(let i=this.start;i<=this.end;i++){
            yield i;
        }

    }

}
```

### Redux-Saga

Uses generators to model asynchronous workflows.

---

# Iterator vs Generator

| Iterator | Generator |
|----------|-----------|
| Object | Special Function |
| Has next() | Produces next() automatically |
| Manual state | Automatic state |
| Manual implementation | Simple using yield |

# Common Interview Questions

### What is an Iterator?

An object with a `next()` method returning `{ value, done }`.

---

### What is an Iterable?

An object implementing `Symbol.iterator()`.

---

### Difference between Iterable and Iterator?

Iterable creates an iterator.

Iterator produces values.

---

### What is a Generator?

A special function (`function*`) that automatically creates an iterator.

---

### What does yield do?

Pauses execution, returns a value, and resumes from the same point.

---

### Difference between yield and return?

| yield | return |
|--------|---------|
| Pause | Finish |
| Resume later | Cannot resume |
| Multiple values | One final value |

---

### Why are Generators used?

- Lazy evaluation
- Infinite sequences
- Large data processing
- Custom iterables
- Redux-Saga

# Common Mistakes

❌ Thinking `Symbol.iterator` is an iterator.

It is a function that **returns** an iterator.

---

❌ Thinking Arrays are Iterators.

Arrays are **Iterables**, not Iterators.

---

❌ Calling

```javascript
arr.next();
```

Arrays don't have `next()`.

Correct

```javascript
arr[Symbol.iterator]().next();
```

---

❌ Thinking plain objects are iterable.

```javascript
for(const x of {})
```

Throws

```text
TypeError: object is not iterable
```
