# 📘 JavaScript Functions - Short Notes

## 📖 What is a Function?

A **function** is a reusable block of code designed to perform a specific task.

```javascript
function greet() {
    console.log("Hello");
}

greet();
```

---

# 📌 Why Use Functions?

- Code Reusability
- Better Readability
- Easy Maintenance
- Avoid Code Duplication
- Modular Programming

---

# 📌 Types of Functions

## 1. Function Declaration

```javascript
function greet() {
    console.log("Hello");
}
```

- Hoisted
- Can be called before declaration

---

## 2. Function Expression

```javascript
const greet = function () {
    console.log("Hello");
};
```

- Not fully hoisted
- Stored in a variable

---

## 3. Named Function Expression

```javascript
const greet = function welcome() {
    console.log("Hello");
};
```

- Internal name (`welcome`) available only inside the function.
- Useful for recursion and debugging.

---

## 4. Anonymous Function

```javascript
const greet = function () {
    console.log("Hello");
};
```

- No explicit function name.
- Mostly used in callbacks.

---

## 5. Arrow Function

```javascript
const greet = () => {
    console.log("Hello");
};
```

- Short syntax.
- Doesn't have its own `this`, `arguments`, or `prototype`.

---

## 6. IIFE (Immediately Invoked Function Expression)

```javascript
(function () {
    console.log("Executed");
})();
```

- Executes immediately after creation.

---

## 7. Callback Function

```javascript
setTimeout(function () {
    console.log("Executed");
}, 1000);
```

- Passed as an argument to another function.

---

## 8. Higher-Order Function

```javascript
function calculate(a, b, operation) {
    return operation(a, b);
}

calculate(10, 20, (a, b) => a + b);
```

- Takes a function as an argument or returns a function.

---

# 📌 Function Components

```javascript
function add(a, b) {
    return a + b;
}
```

- Function Keyword → `function`
- Function Name → `add`
- Parameters → `a`, `b`
- Function Body → `{ return a + b; }`
- Return Value → `a + b`

---

# 📌 Parameters vs Arguments

```javascript
function greet(name) {
    console.log(name);
}

greet("Anil");
```

| Parameter | Argument |
|-----------|----------|
| Variable in function definition | Actual value passed during function call |

---

# 📌 Return Statement

```javascript
function square(num) {
    return num * num;
}
```

- Ends function execution.
- Returns a value.

---

# 📌 First-Class Functions

JavaScript treats functions as first-class citizens.

Functions can:

- Be assigned to variables.
- Be passed as arguments.
- Be returned from functions.
- Be stored in objects or arrays.

---

# 📌 Function Hoisting

### Function Declaration

```javascript
greet();

function greet() {
    console.log("Hello");
}
```

✅ Works

---

### Function Expression

```javascript
greet();

const greet = function () {};
```

❌ ReferenceError

---

# 📌 `this` Behavior

| Function Type | Own `this`? |
|--------------|-------------|
| Normal Function | ✅ Yes |
| Arrow Function | ❌ No (inherits from lexical scope) |

---

# 📌 Common Interview Questions

### Difference between Function Declaration and Function Expression?

| Function Declaration | Function Expression |
|----------------------|--------------------|
| Fully hoisted | Not fully hoisted |
| Has a function name | Can be anonymous |
| Declared using `function` | Assigned to a variable |

---

### Difference between Parameters and Arguments?

- Parameters → Variables in function definition.
- Arguments → Actual values passed during function call.

---

### Difference between Normal Function and Arrow Function?

| Normal Function | Arrow Function |
|-----------------|----------------|
| Own `this` | Lexical `this` |
| Has `arguments` | No `arguments` |
| Can be constructor | Cannot be constructor |
| Has `prototype` | No `prototype` |

---

# 📝 Summary

- Functions are reusable blocks of code.
- JavaScript functions are first-class citizens.
- Functions can be declarations, expressions, anonymous, named expressions, arrow functions, IIFEs, callbacks, or higher-order functions.
- Function declarations are hoisted, while function expressions are not.
- Arrow functions differ mainly in `this`, `arguments`, `prototype`, and constructor behavior.
